# 📄 ScanMyResume

**Created by Keshav**

ScanMyResume is a modern, AI-powered resume analyzer that gives candidates actionable feedback based on job descriptions. Upload your resume, get instant ATS-style scoring, and track your application performance — all in one place.

---

## 🚀 Features

- 🔍 **AI-Powered Resume Scanning** – Receive personalized feedback based on your uploaded resume and job description.
- 🎯 **ATS Score Evaluation** – Simulates how Applicant Tracking Systems (ATS) assess your resume.
- 📂 **Resume Upload & Management** – Store and organize multiple resumes securely.
- 📊 **Visual Score Insights** – View your resume performance using intuitive visualizations.
- 💡 **Modern UI/UX** – Built with Tailwind CSS and shadcn/ui for a clean and responsive interface.
- 🌐 **Serverless by Design** – Powered by Puter.js for secure, serverless storage and authentication.

---

## 🛠 Tech Stack

- **React** – Frontend library for building UI components.
- **React Router v7** – Handles dynamic routing and navigation.
- **Puter.js** – Provides serverless backend (auth, file storage, and AI APIs).
- **Tailwind CSS** – Utility-first CSS for rapid UI development.
- **TypeScript** – Adds static typing and better developer tooling.
- **Vite** – Fast build tool and dev server.
- **Zustand** – Lightweight state management.
